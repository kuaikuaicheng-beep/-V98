## V91 付款圖片確認規則
- 店長只有在訂單已偵測到客人付款成功明細圖片後，才會看到「💰 確認付款」按鈕。
- 沒有圖片時，即使舊訊息仍存在確認按鈕，點擊也會再次檢查並拒絕確認。
- 圖片偵測不再依賴 `TICKET_CHANNEL_IDS` 快取。
- 支援 PNG / JPG / JPEG / WEBP / GIF / BMP / HEIC / HEIF。
- 圖片可以在客人按「完成付款」後上傳，也能在按鈕前先上傳；店長確認前都會檢查。
- 客人按「💳 完成付款」後會收到：`✅ 成功提交付款通知，請等待店長`

## V98 全新改名工單
- `/改名工單` 完全在 Slash Command 輸入框操作。
- 欄位：服務、狀態、額度、數量。
- 幣號狀態：待付款、處理中、待交貨；額度：50M、100M、200M；數量 1～1000。
- 代肝狀態：待倒、待付款、處理中；額度：50M～1000M，每 100M 一級；不用填數量。
- 工單號自動從目前工單名稱或資料庫辨識並保留，送出後直接改名，不建立面板。
- `/自動排序工單號`／`/排序工單號` 依原工單號大小重新連號。
